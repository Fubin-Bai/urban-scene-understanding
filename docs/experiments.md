# 实验记录

## 数据与任务

- Cityscapes fine split：2,975 张训练图，500 张验证图。
- 语义任务：19 类，void 像素忽略。
- 实例任务：8 个 thing 类。
- validation 用于选模和报告。本项目没有 test server 结果。

## 配置

| 项目 | 设置 |
|---|---|
| 输入 | 256x512 |
| batch size | 2 |
| 优化器 | AdamW |
| learning rate | 1e-4 |
| weight decay | 1e-4 |
| 训练轮数 | 5 |
| seed | 9444 |
| GPU | Tesla T4 |
| 语义环境 | PyTorch 2.11，CUDA 12.8 |
| 实例环境 | PyTorch 2.11，CUDA 13.0 |

三个语义实验共用 ImageNet 初始化。实例实验使用 COCO 初始化并替换 box 和 mask 预测头。四个实验使用相同划分和划分指纹。

|---|---|---|---|---|

S0 和 S1 比较语义头；S1 和 S2 比较翻转增强。I0 是独立实例基线，不属于同一消融序列。

接触率不能解释 AP/AP50 的分组。面积和宽度相关更强，但样本只有 8 个类别，因此结论属于探索性分析。

实例 AP 与语义 IoU 的 Spearman 相关为 S0 0.690、S1 0.548、S2 0.714。

## 分析顺序

1. 从四个完整运行读取最佳 checkpoint 和 validation 导出。
2. 用同一实例 checkpoint 比较 cap=50、100、200。
3. 选择不触顶且 AP 最高的 cap=200 导出。
4. 用该导出重算逐类 AP、跨任务相关、接触率和几何相关。
5. 从相同结果生成 Notebook 输出、报告图片和 PPT 数字。

所有实例分析统一使用 cap=200 导出。

## 限制

- validation 同时用于选模和报告，结果可能偏高。
- 每个配置只有一个 seed，没有误差条。
- 输入为四分之一分辨率，且没有 learning-rate schedule。
- I0 最后一轮仍在提升，结果不是收敛值。
- Mask R-CNN 训练时将 group regions 视为背景。
- 没有 test server 结果。
